# 📚 Common Terms Used in Electrician Work — With Practical Examples

## ⚡ Basic Electrical Terms

| Term           | Meaning                                                    | Practical Example                                |
|----------------|------------------------------------------------------------|--------------------------------------------------|
| Voltage (V)    | Electrical pressure that pushes current through a circuit. | India home supply = **230V AC**.                 |
| Current (A)    | Flow of electric charge through a conductor.               | A geyser draws **10A–16A** typically.            |
| Resistance (Ω) | Opposition to current flow.                                | A bad connection increases resistance → heating. |
| Power (W)      | Voltage × Current.                                         | A 1000W heater at 230V uses ~4.3A.               |
| Load           | Device that consumes electricity.                          | Fan, light, AC, washing machine.                 |
| Phase (Live)   | Carries current from supply.                               | Touching it with bare hands → shock risk.        |
| Neutral        | Returns current to supply.                                 | Should not give shock if wiring is correct.      |
| Earth (Ground) | Safety path for faults.                                    | Metal fridge body connected to earth.            |

## 🔌 Wiring & Cable Terms

| Term                       | Meaning                               | Practical Example                    |
|----------------------------|---------------------------------------|--------------------------------------|
| Conductor                  | Metal that carries current.           | Copper wire inside PVC insulation.   |
| Insulation                 | Non-conductive coating.               | Plastic layer preventing shocks.     |
| Cable Sheath               | Outer jacket around multi-core cable. | 3-core house wiring cable.           |
| Single-Core Wire           | One conductor.                        | Standard wires inside conduits.      |
| Stranded Wire              | Flexible, multi-strand conductor.     | Used in appliances, extension cords. |
| Gauge (AWG)                | Wire size system (US).                | AWG 12 ≈ 3mm² wire.                  |
| Cross-Sectional Area (mm²) | Wire size in India/EU.                | Sockets use **2.5 mm²** wire.        |

## 🛠️ Electrical Component Terms

| Term                    | Meaning                                            | Practical Example                              |
|-------------------------|----------------------------------------------------|------------------------------------------------|
| Switch                  | Turns load ON/OFF.                                 | Light switch in any room.                      |
| Socket / Outlet         | Point to connect appliances.                       | 6A socket for mobile chargers.                 |
| MCB                     | Trips during overload/short circuit.               | AC MCB trips when AC draws excess current.     |
| RCD / RCCB              | Protects from electric shock by leakage detection. | RCCB trips if water enters washing machine.    |
| Distribution Board (DB) | Panel containing breakers.                         | Main electrical board of a house.              |
| Busbar                  | Metal strip distributing power.                    | Copper busbar inside DB feeding multiple MCBs. |
| Junction Box            | Box where wires connect.                           | Hidden box in ceiling for light wiring.        |
| Terminal Block / Wago   | Connector for joining wires.                       | Using Wago to connect fan wires.               |
| Conduit                 | Pipe carrying wires.                               | PVC pipe running electrical wires in walls.    |

## 🔧 Measurement & Testing Terms

| Term                       | Meaning                                       | Practical Example                               |
|----------------------------|-----------------------------------------------|-------------------------------------------------|
| Multimeter                 | Measures voltage/current/resistance.          | Checking whether a socket has 230V.             |
| Clamp Meter                | Measures current without disconnecting wires. | Checking AC current draw by clamping live wire. |
| Continuity Test            | Checks wire path is intact.                   | Testing if a switch wire is broken.             |
| Polarity Test              | Checks correct Live/Neutral wiring.           | Ensuring socket isn't wired in reverse.         |
| Insulation Resistance Test | Measures insulation health.                   | Used in old houses to detect leakage.           |
| Voltage Tester (Pen)       | Detects live wire without contact.            | Touching phase wire → tester lights up.         |

## 🔥 Safety Terms

| Term                 | Meaning                                  | Practical Example                                      |
|----------------------|------------------------------------------|--------------------------------------------------------|
| Earthing / Grounding | Protects from shock.                     | Earth wire prevents shock if fridge body becomes live. |
| Short Circuit        | Live touches Neutral/Earth directly.     | Damaged wire causing sparks in switchboard.            |
| Overload             | Too much current in circuit.             | Running heater + iron on same socket.                  |
| Arc Fault            | Electrical discharge from loose contact. | Crackling noise from switch → loose screws.            |
| Trip                 | MCB turns off automatically.             | MCB trips when mixer motor jams.                       |
| Shock Hazard         | Risk of electric shock.                  | Handling wires with wet hands.                         |

| DC Supply        | Direct current.                | Batteries, solar panels.                  |

## 📏 Electrical Standards & Ratings

| Term                 | Meaning                        | Practical Example                      |
|----------------------|--------------------------------|----------------------------------------|
| Wattage Rating       | Max load a device can handle.  | A switch rated 6A cannot run a heater. |
| IP Rating            | Dust/water protection.         | IP65 outdoor LED light.                |
| Breaker Rating (Amp) | Current limit of an MCB.       | 16A MCB used for geyser circuit.       |
| Wire Rating          | Safe current capacity of wire. | 2.5mm² wire handles ~18–20A.           |
| ISI / CE Standards   | Safety certification marks.    | ISI-marked house wiring cable.         |
