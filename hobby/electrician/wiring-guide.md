# 1️⃣ Introduction

This handbook is designed to help you safely understand and perform basic household electrical work such as:

- Replacing switches
- Replacing sockets
- Extending wires
- Identifying live/neutral
- Using a multimeter
- Basic circuit troubleshooting

⚠️ Warning:  
Only perform low-risk tasks. For high-load circuits, burning smell, exposed wires, or repeated MCB tripping—call a
licensed electrician.

# 5️⃣ Circuit Basics

## Key Terms

- Live (Phase): Carries current from power source
- Neutral: Returns current
- Earth (Ground): Safety path
- MCB: Protects from overload and short circuit
- Load: Device using electricity

## Basic Loop for a Light

MCB → Live → Switch → Light → Neutral → MCB

## Basic Power Socket Wiring

Live → Socket Live  
Neutral → Socket Neutral  
Earth → Socket Earth

# 6️⃣ Installing / Replacing Switches

## Steps

1. Turn OFF MCB.
2. Verify wires are dead using a non-contact tester.
3. Remove faceplate.
4. Identify live wire.
5. Connect Live → Switch → Load.
6. Tighten screws.
7. Replace plate and restore power.

## Important

- Only the **live wire** should go through the switch.
- Never put neutral on the switch.

---

# 7️⃣ Installing / Replacing Sockets

## Steps

1. Turn OFF MCB.
2. Confirm zero voltage.
3. Identify Live, Neutral, Earth.
4. Connect wires to correct terminals.
5. Tighten screws firmly.
6. Test with socket tester or multimeter.

## Safety

- Do not overload terminals.
- Ensure Earth wire is always connected.

# 8️⃣ Using a Multimeter (Quick Reference)

## Measure AC Voltage

Dial → V~  
Black probe → COM  
Red probe → VΩ  
Insert probes into socket  
Read ~220–240V

## Continuity Test

Dial → Continuity  
Touch both ends of wire  
Beep = Wire OK

## Identify Live Wire

Dial → AC Voltage  
Black probe → Neutral  
Red probe → Test wires  
220–240V = Live

# 9️⃣ Safety Checklist

## Before Work

- Turn OFF MCB
- Confirm no voltage
- Use insulated tools
- Hands must be dry

## During Work

- Never mix wire sizes
- Use Wago/terminal blocks
- Avoid loose connections
- Keep junction boxes accessible

## After Work

- Test switch/socket
- Check for heat
- Label circuits
- Retighten screws

# 🔟 Troubleshooting Guide

## Light Flickering

- Loose terminal
- Weak connection  
  Fix: Tighten or replace switch

## Socket Not Working

- Loose wire
- Broken neutral  
  Fix: Check continuity and wiring

## MCB Tripping

- Short circuit
- Overload  
  Fix: Unplug everything and test one by one

## Burning Smell

Stop immediately.  
Turn OFF MCB and call electrician.
