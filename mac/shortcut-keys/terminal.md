macOS Terminal Keyboard Shortcuts
═══════════════════════════════════════════════

# Cursor Movement
Ctrl + A        Beginning of line
Ctrl + E        End of line
Option + ←      Previous word
Option + →      Next word
Ctrl + B        Back one character
Ctrl + F        Forward one character

# Editing
Ctrl + U        Delete from cursor to beginning
Ctrl + K        Delete from cursor to end
Ctrl + W        Delete previous word
Option + D      Delete next word
Ctrl + D        Delete character under cursor
Delete          Delete previous character
Ctrl + T        Transpose characters
Option + T      Transpose words

# Clipboard / Kill Ring
Ctrl + Y        Paste last killed text
Ctrl + _        Undo last edit (Bash)
Cmd + C         Copy selected text
Cmd + V         Paste
Cmd + X         Cut selected text

# History
↑               Previous command
↓               Next command
Ctrl + P        Previous command
Ctrl + N        Next command
Ctrl + R        Reverse search history
Ctrl + G        Exit history search
!!              Repeat previous command
!<number>       Run command by history number
!<text>         Run last command starting with text
history         Show history

# Screen
Ctrl + L        Clear screen
clear           Clear screen
Cmd + K         Clear terminal scrollback

# Process Control
Ctrl + C        Interrupt process
Ctrl + Z        Suspend process
fg              Resume foreground
bg              Resume background
jobs            List background jobs
exit            Exit shell
logout          Logout shell

# Tab Completion
Tab             Auto-complete
Tab Tab         Show possible completions

# Terminal Tabs & Windows
Cmd + T         New tab
Cmd + W         Close tab
Cmd + N         New window
Cmd + Shift + ] Next tab
Cmd + Shift + [ Previous tab

# Selection
Shift + Click   Select text
Option + Click  Move cursor to clicked position

# Useful Commands
pwd             Current directory
ls              List files
cd              Change directory
cd -            Previous directory
mkdir           Create directory
rm              Remove files
cp              Copy files
mv              Move/Rename files
find            Find files
grep            Search text
cat             Display file
less            View file
head            First lines
tail -f         Follow log
open .          Open current folder in Finder
open file.txt   Open file with default app
pbcopy          Copy stdin to clipboard
pbpaste         Paste clipboard
which cmd       Locate executable
man command     Manual page

# Zsh Specific
Ctrl + R        Fuzzy history search
Alt + .         Insert last argument
Ctrl + X Ctrl + E  Edit command in editor
