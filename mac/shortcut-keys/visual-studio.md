Visual Studio Code (macOS) Shortcuts
══════════════════════════════════════════════════════════════

# General
⌘ + P              Quick Open
⌘ + Shift + P      Command Palette
⌘ + ,              Settings
⌘ + K ⌘ + S        Keyboard Shortcuts
⌘ + Q              Quit VS Code
⌘ + W              Close Editor
⌘ + Shift + W      Close Window

# Explorer
⌘ + Shift + E      Explorer
⌘ + Shift + F      Search
⌘ + Shift + G      Source Control
⌘ + Shift + D      Run & Debug
⌘ + Shift + X      Extensions

# Navigation
⌘ + Click          Go to Definition
F12                Go to Definition
⌥ + F12            Peek Definition
⌘ + T              Go to Symbol in Workspace
⌘ + Shift + O      Go to Symbol in File
Ctrl + G           Go to Line
Ctrl + Tab         Next Editor
Ctrl + Shift + Tab Previous Editor
⌘ + ←              Beginning of Line
⌘ + →              End of Line
⌥ + ←              Previous Word
⌥ + →              Next Word

# Editing
⌘ + C              Copy
⌘ + X              Cut
⌘ + V              Paste
⌘ + Z              Undo
⌘ + Shift + Z      Redo
⌘ + A              Select All
⌘ + F              Find
⌥ + Enter          Select All Matches
⌘ + H              Replace
⌘ + Shift + H      Replace in Files

# Multi Cursor
⌥ + Click          Add Cursor
⌥ + ⌘ + ↑          Add Cursor Above
⌥ + ⌘ + ↓          Add Cursor Below
⌘ + D              Select Next Occurrence
⌘ + Shift + L      Select All Occurrences

# Line Operations
⌥ + ↑              Move Line Up
⌥ + ↓              Move Line Down
Shift + ⌥ + ↑      Duplicate Line Up
Shift + ⌥ + ↓      Duplicate Line Down
⌘ + /              Toggle Line Comment
Shift + ⌥ + A      Toggle Block Comment
⌘ + Enter          Insert Line Below
⌘ + Shift + Enter  Insert Line Above
⌘ + Backspace      Delete Line Left
Ctrl + K           Delete Line

# Folding
⌥ + ⌘ + [          Fold
⌥ + ⌘ + ]          Unfold
⌘ + K ⌘ + 0        Fold All
⌘ + K ⌘ + J        Unfold All

# Terminal
Ctrl + `            Toggle Terminal
⌘ + Shift + `       New Terminal
⌘ + Shift + C       Open External Terminal

# Problems & Output
⌘ + Shift + M      Problems
⌘ + Shift + U      Output
⌘ + Shift + Y      Debug Console

# Files
⌘ + N              New File
⌘ + O              Open File
⌘ + Shift + N      New Window
⌘ + Shift + T      Reopen Closed Editor
⌘ + S              Save
⌘ + Shift + S      Save As
⌥ + ⌘ + S          Save All

# Search
⌘ + Shift + F      Search in Workspace
F3                 Find Next
Shift + F3         Find Previous

# Git
Ctrl + Shift + G   Source Control
⌘ + Enter          Commit (when message focused)

# Split Editors
⌘ + \              Split Editor
⌘ + 1              Focus Editor Group 1
⌘ + 2              Focus Editor Group 2
⌘ + 3              Focus Editor Group 3

# Zoom
⌘ + +              Zoom In
⌘ + -              Zoom Out
⌘ + 0              Reset Zoom
